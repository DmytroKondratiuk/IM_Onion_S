# ІМ Onion-S — Імітаційна модель цифрової трансформації агропродовольчих підприємств

Імітаційне моделювання стратегічного управління цифровою трансформацією на базі **System Dynamics** + **ланцюги Маркова**. Модель генерує синтетичні підприємства (3 прогони × 200 у дефолтному відтворюваному режимі; до 10 × 1000 у повному), калібрує штрафні параметри α та δ формули ADMI, проводить сценарний аналіз 5 стратегій на горизонтах 5/10/15 років, крос-валідує SD-результати через матриці Маркова та виконує аналіз чутливості параметрів.

Результати — структурований xlsx-звіт із 20 листів (таблиці + вбудовані графіки + conditional-formatting heatmap-и) і набір PNG-графіків для вставки у публікації.

Частина дисертаційного дослідження (PhD Economics, спеціальність 051). Кожен файл звіту записується обома мовами за один прогін: англійською без суфікса, українською з `.uk` перед розширенням (наприклад, `onion_s_simulation.xlsx` і `onion_s_simulation.uk.xlsx`).

## Швидкий старт

```bash
# 1. Встановити залежності (один раз)
pip3 install -r requirements.txt

# 2. Запустити повний цикл
python3 generate_report.py
```

Скрипт запитає мову повідомлень у консолі (`uk` / `en`), запустить моделювання і збереже результати обома мовами у:
- `results/simulation_report.json` — сирі дані (не залежать від мови)
- `results/onion_s_simulation.uk.xlsx`, `results/onion_s_simulation.xlsx` — повний xlsx-звіт, українською / англійською
- `figures/stock_flow{,.uk}.png`, `figures/stock_flow{,.uk}.dot` — Stock-and-Flow діаграма, англійською / українською

## CLI-прапорці

| Прапор | Опис |
|---|---|
| `--lang uk` / `--lang en` | Мова повідомлень у консолі (без інтерактивного запиту); файли завжди пишуться обома мовами |
| `--quick` | Швидкий режим: 200 підприємств × 3 запуски (≈8 с замість ≈3–5 хв) |
| `--no-multi` | Пропустити багатогоризонтний аналіз (10/15 років) |
| `--export-pngs` | Згенерувати PNG для всіх 5 основних графіків + 4 теплових карт |
| `--output-dir PATH` | Альтернативна папка для JSON/xlsx (default: `./results`) |
| `--figures-dir PATH` | Альтернативна папка для PNG/.dot (default: `./figures`) |
| `--sequence` | Після основного pipeline запустити ще експеримент S5 із послідовністю (≈ 20 с – 2 хв) |
| `--sequence-only` | Запустити лише експеримент S5, без основного pipeline |

## Що генерується

### `results/simulation_report.json`
Структурований JSON з усіма сирими даними: калібрація, траєкторії ADMI, покомпонентні DM, матриці переходу Маркова, стаціонарні розподіли, час досягнення рівнів, чутливість параметрів, багатогоризонтні результати.

### `results/onion_s_simulation.uk.xlsx` (українською) і `results/onion_s_simulation.xlsx` (англійською)
20 листів, розділені на 2 групи:

**Таблиці-результати (15 листів):**
- Про звіт (метадані запуску)
- Калібрація (α*, δ*, J, C₁, C₂, C₃ по 10 запусках)
- Теплова карта J(α,δ) з conditional formatting
- Деградація d_k
- Сценарії ADMI (траєкторії mean/std/median/p25/p75)
- Сценарії DM компоненти (покомпонентні DM_i по роках)
- Рівні розподіл (розподіл підприємств по 5 рівнях зрілості)
- 3× Матриці Маркова (С-1/С-2/С-3) з heatmap через conditional formatting
- Стаціонарні розподіли π
- Час досягнення рівня (hitting times)
- Багатогоризонтний (ΔADMI 5/10/15)
- Крос-валідація (SD vs Маркова)
- Чутливість (OAT ±20%)

**Листи з графіками (5 листів, openpyxl-charts без заголовків):**
- Траєкторії ADMI (LineChart)
- Профілі DM (RadarChart)
- Багатогоризонтний (BarChart)
- Крос-валідація (BarChart)
- Чутливість (Tornado BarChart)

### `results/sequence_experiment.*` (з `--sequence` / `--sequence-only`)

Результати експерименту S5 із послідовністю (див. нижче). Експеримент рахується один раз і завжди пише обидві мовні версії, незалежно від `--lang`:

| Файл | Вміст |
|---|---|
| `sequence_experiment.json` | сирі дані (не залежать від мови) |
| `sequence_experiment.uk.xlsx` / `sequence_experiment.xlsx` | таблиці й діаграми, українською / англійською |
| `sequence_experiment.uk.md` / `sequence_experiment.md` | ті самі таблиці в Markdown, українською / англійською |

xlsx має 6 аркушів: «Про експеримент» (параметри дизайну), результати за горизонтами (ADMI, DM_I, випуск, частка рівня ≥ 4, стани шарів), τ Кендалла, парні різниці з 95 % ДІ і два аркуші з діаграмами (ADMI за правилами й горизонтами, парні ΔADMI). Файли md повторюють ті самі таблиці в Markdown; українська версія з десятковою комою.

## Відтворюваність опублікованих результатів

Закомічені `results/` і `figures/` (обидві мовні версії) отримано **дефолтним детермінованим прогоном**:

```bash
python3 generate_report.py --lang uk --quick --export-pngs
```

Цей прогін використовує фіксовані дисертаційні зерна (`DEFAULT_SEEDS` у `generate_report.py`) і швидкий дизайн **3 незалежні прогони × 200 синтетичних підприємств** (разом 600) з багатогоризонтним блоком (5/10/15 років). Усі числа, наведені в дисертації та в пов'язаній журнальній статті (калібровані α = 0,40, δ = 0,375; базовий ADMI 0,393 → 0,348 за 5 років і −0,121 за 15 років; +0,029 для стратегії ядра; зростання у 3,5 раза для інтеграційної стратегії), відтворюються цією командою точно. Повний режим (10 прогонів × 1000 підприємств, запуск без `--quick`) доступний для перевірки стійкості, але не є джерелом опублікованих чисел. Ключ `--seed N` породжує інший набір зерен і тому дає інші значення.

### Експеримент із послідовністю (v1.2.0)

Статичні сценарії тримають незмінні частки бюджету на весь горизонт і тому не реалізують *послідовності* інвестицій. Експеримент із послідовністю (`src/sequence_experiment.py`) вимірює ціну відхилення від порядку шарів C → L1 → L2 → L3 → L4 всередині моделі:

```bash
python3 generate_report.py --lang uk --sequence-only   # ≈ 20 с – 2 хв, пише results/sequence_experiment.* (uk + en)
python3 src/sequence_experiment.py --lang uk           # те саме, окремий запуск
```

Три динамічні правила з однаковою інтенсивністю бюджету щокварталу обирають фокусний шар (55 % бюджету; решта операційних шарів по 5 %, інтеграція 15 %, стратегічна готовність 10 %). Ціль піднімається сходами δ = 0,375 → 0,60 → 0,80. *inner_first* обирає найвнутрішніший шар нижче цілі, *weakest_first* найслабший незалежно від порядку, *outer_first* найзовнішніший нижче цілі; статичні *uniform* і *S2_core* додано для порівняння. Парний дизайн: ті самі 200 підприємств і те саме зерно шуму для кожного правила, 10 повторів (зерна 1000 + 97·k), зовнішній тиск нуль.

Ключові результати на 15 років: inner_first − outer_first ΔADMI +0,031 (95 % ДІ 0,030–0,032), Δвипуск +0,023; inner_first − weakest_first ΔADMI +0,011, Δвипуск −0,003; S2_core − uniform ΔADMI +0,005, Δвипуск −0,035. Експеримент **не** перевіряє аксіому 1 — вона закладена в множник внутрішніх шарів, — а вимірює величину ефекту порядку за припущень моделі.

## Імпорт `.dot` у draw.io

Stock-and-Flow діаграма зберігається у двох форматах: PNG (готовий для вставки у публікацію) і **.dot** (Graphviz), який можна імпортувати у draw.io для доопрацювання:

1. Відкрити <https://app.diagrams.net> (або десктоп).
2. **File → Import → Device…**
3. Вибрати `figures/stock_flow.dot`.
4. За потреби — у діалозі імпорту вибрати «Graphviz (.dot)».

## Конфігурація

Усі параметри моделі зібрані в `src/onion_s_simulation.py`, словник `CONFIG`:

```python
CONFIG = {
    "n_enterprises": 1000,            # розмір вибірки
    "n_runs": 10,                     # незалежних запусків калібрації
    "n_years": 5,                     # горизонт
    "dt": 0.25,                       # квартальний крок
    "alpha_range": np.arange(...),    # грід для α
    "delta_range": np.arange(...),    # грід для δ
    "budget_total": 0.40,             # бюджет за квартал
    "investment_efficiency": 0.55,    # η
    "absorptive_saturation": 0.4,     # σ (поглинальна зд.)
    "integration_power": 0.5,         # β (інтеграційна степ. ф.)
    "scenarios": { ... },             # 5 векторів розподілу бюджету
    ...
}
```

Нові сценарії додаються у `CONFIG["scenarios"]` + переклади у `src/i18n.py` (`SCENARIO_KEY_MAP` + UK/EN словники). Параметри експерименту з послідовністю (частки бюджету, сходи цілі, кількість повторів) задано константами на початку `src/sequence_experiment.py`; його мітки — ключі `seq_*` у `src/i18n.py`.
